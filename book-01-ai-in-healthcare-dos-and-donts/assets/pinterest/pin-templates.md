## Canva Steps (Repeatable)

1. Go to **canva.com** → **Create a design** → **Custom size** → `1000 × 1500`
2. Set **background color** to `#1B2A4A` (deep navy)
3. Add **text** → use Montserrat Bold for titles, Open Sans for body
4. Add **elements** → search "checklist", "shield", "arrow" for icons
5. Add **book cover** image (drag from uploads)
6. Add **CTA text** in teal (`#00BFA5`): "FREE GUIDE ↓"
7. Download as **PNG** (highest quality)
8. Upload to Pinterest with SEO description

---

## Batch Creation (Faster)

1. Create **one** template in Canva
2. Click **Duplicate page** → change text → repeat
3. Export all as PNGs → upload to Pinterest
4. Schedule in Pinterest app (5/day)
